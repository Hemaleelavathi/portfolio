# Personal Portfolio Website

A clean, responsive, and modern personal portfolio website developed by **Hema Leelavathi N** to showcase academic background, technical skills, featured software projects, and contact information.

---

## 📖 About The Project

This repository hosts the source code for my personal portfolio website. Built with a focus on simplicity, responsiveness, and performance, it provides visitors, recruiters, and collaborators with an intuitive overview of my profile, educational qualifications, core technical proficiencies, and software engineering projects.

The website features an elegant dark theme design with smooth transitions and interactive 3D card hover effects.

---

## ✨ Features

- **Responsive Design**: Adapts seamlessly to various screen sizes, including mobile devices, tablets, and desktops.
- **Modern Dark Theme UI**: Sleek black aesthetic with sky-blue accents (`#38bdf8`) for high contrast and readability.
- **Interactive 3D Card Hover Effects**: Dynamic perspective transforms and glowing shadows on project, education, and skill cards.
- **Smooth Navigation**: Fixed header with intuitive navigation links directing to specific sections of the page.
- **One-Click Resume Download**: Direct download trigger for the latest resume PDF (`HemaResume.pdf`).
- **External Project Links**: Direct access to GitHub repositories for each showcased project with `target="_blank"` security.
- **Zero Dependencies**: Pure HTML, CSS, and Vanilla JavaScript with no external framework dependencies, ensuring instant load times.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic document structure (`<header>`, `<nav>`, `<section>`, `<footer>`, etc.).
- **CSS3**: Custom dark theme styling, Flexbox layout, interactive 3D transforms (`rotateX`, `rotateY`, `translateY`), backdrop filters, transitions, and hover effects.
- **JavaScript (Vanilla JS)**: Client-side interactive scripting and event handling.

## 💻 How to Run the Project Locally

To run and view the portfolio website locally on your computer:

### Prerequisites
A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, etc.).

### Steps

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Hemaleelavathi/portfolio.git
   ```

2. **Navigate into the project directory:**
   ```bash
   cd portfolio
   ```

3. **Open the website:**
   - **Option A (Direct)**: Double-click `index.html` or open it with your favorite browser.
   - **Option B (VS Code Live Server)**: Right-click `index.html` in VS Code and select **Open with Live Server**.
   - **Option C (Python local server)**:
     ```bash
     python -m http.server 8000
     ```
     Then visit `http://localhost:8000` in your browser.
